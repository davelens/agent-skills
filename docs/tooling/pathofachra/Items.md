# Items

Items can be equipped by your character to increase their stats and add various effects. They come in the forms of weapons/shields, head, arm, chest and leg armor. Your character has two slots for weapons/shields and 1 slot for each armor piece.

Every class has an initial set of items automatically equipped. More items can be found lying on the floor, as you go through the areas of the game mostly on the last stage of an area.

One file per item in `items/` (168 items), with stats, resistances and effects. Sorted by name within each slot.
